# VRM Lantern Viewer

**視点追従型立体視（覗き窓効果）に対応した、単一HTMLの3Dモデルビューアー**

日本語 | [English](README.en.md)

## 概要

視点追従型立体視（覗き窓効果）を利用した、ランタン（カンテラ）型の表示デバイスを作りたくて、そのシミュレーション用に作ったモデルビューアーです。HTML形式なので、PC・携帯・タブレットを複数台使って、ブラウザーだけで動作をイメージできます。

前面カメラで顔を認識し、その人から見たモデルが実際にそこにあるように見せることを目指しています。前面カメラは画角が狭いため効果は「それなり」ですが、楽しんでいただけると幸いです。改造等はご自由にどうぞ。

インストール不要。対応ブラウザーがあれば Windows・macOS・Linux・iPhone・Android で動きます（外部ライブラリと顔追跡モデルの取得のため、オンライン環境が必要です）。

※ iPhoneなどでHTMLファイルを直接開くのが難しい場合は、下記「使い方」に記載のオンライン版（GitHub Pages）をご利用ください。

## 主な特徴

- **単一HTML・インストール不要**：ブラウザーで開くだけ
- **視点追従型立体視**：顔追跡（MediaPipe）と傾きセンサーによるオフアクシス投影
- **1〜8面のレイアウト**：単一画面から多面体表示、立体プレビューまで切り替え
- **複数端末連携（WebRTC）**：現在は2面構成（母機＋子機1台）。自動接続（ntfy.sh）または手動コードで接続。将来的に最大8面へ拡張予定
- **環境・演出**
  - 昼夜・空・雲・星のシェーダー描画
  - 粒エフェクト（蛍・雪・花びら・雨）
  - 光る妖精（自動飛行・光源追従）
  - 被写界深度（ぼかし）、逆光の光だまり
  - 床写真の遠近補正（4点ホモグラフィ変換）と環境光反映
  - 透過モード（背面カメラ映像を背景にしたAR風表示）
- **モデル・モーション**：VRM / MMDの読み込み、VRM・MMD相互のモーション適用、接地補正、足の交差防止
- **データ保存**：IndexedDB / localStorage にブラウザー内保存

## 使い方（最短）

最新版は、下記のGitHub Pagesに常に置いてあります。

https://390-b-sou.github.io/vrm_lantern/

ブックマークして、デスクトップやホーム画面に置いておくと便利です。

1. `index.html` をブラウザーで開く
2. **メニュー → ファイル関係 → モデルを追加** で `.vrm` / `.zip` / `.pmx` を読み込む
3. **カメラ開始** を押し、カメラを許可する（iPhoneは傾きセンサーの許可も求められます）
4. 顔を動かすと視点に追従します
5. 動かすには **モーション（.vrma / .vmd）** を追加して **再生**
6. 背景・床・粒・妖精は **背景設定** から選択

## 対応形式

| 種類 | 形式 |
|---|---|
| モデル | `.vrm` `.zip` `.pmx` `.pmd`（MMD一式） `.glb`（小物） |
| モーション | `.vrma` `.vmd` |
| 背景・床 | 画像全般、背面カメラ映像 |
| 音声 | ブラウザーが再生できるオーディオファイル |

## 動作環境・注意点

- 外部ライブラリと学習モデルは CDN（jsDelivr / Google Storage）から取得します。
- 視点追跡と2台連携には、カメラの許可とインターネット接続が必要です。
- WebGL・WebRTC・DeviceOrientation 等のブラウザー標準機能を使います。対応状況と性能は、ブラウザーや端末によって異なります。
